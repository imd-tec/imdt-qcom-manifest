# imdt-qcom-manifest

Manifest for additional yocto meta layers for the IMDT Qualcomm SBCs.

# Manifests

* ```default.xml```: Build latest version.
* ```default-dev.xml```: Used for internal deployment testing by IMDT.
* ```development.xml```: Used for internal development by IMDT.
* Other: Versioned releases.

# Usage

At the time of writing, to build with this manifest use the 
```sync_repo.sh``` script. Refer to Getting started guide or build instructions.
